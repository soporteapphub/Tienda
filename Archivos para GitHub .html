Archivos del proyecto

  1. En el celular abre github.com en Chrome, menú ⋮ y activa «Sitio de escritorio».
  2. Crea tu repositorio privado tienda-dvd-tecno.
  3. Dentro: Add file → Create new file. Pega el nombre en la casilla de nombre (las carpetas se crean solas), pega el contenido y toca Commit changes.
  4. Repite en el mismo orden. El último (build.yml) inicia la compilación.
